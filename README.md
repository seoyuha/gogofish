# 🎣 GO GO FISH — 6학년 영어 11·12단원 고피시 게임

같은 카드 4장을 모으면 책 1권! 3~5명이 한 모둠으로, 영어 문장으로 카드를 물어보며 책을 모으는 실시간 게임이에요.

- 학생 화면: `주소/` (예: `https://gogo-fish.onrender.com/?code=6-1`)
- 교사 화면: `주소/teacher`

---

## 1. 수업에서 쓰는 순서

1. 교사 화면(`/teacher`)을 열고 **반 코드**(예: `6-1`)를 정해 [관리 시작]을 눌러요.
2. 화면의 **QR 코드나 주소**를 학생들에게 보여 줘요. 학생은 반 코드와 이름(번호+이름)을 쓰고 들어와요.
3. 그다음부터는 **교사가 버튼을 누를 필요가 없어요.**
   - 대기실에 3명 이상 모이면 3~5명 모둠이 자동으로 만들어지고, 6초 뒤 바로 게임이 시작돼요.
   - 게임이 끝나면 결과를 15초 보여 주고 대기실로 돌아가요. 그리고 **새 모둠**에 자동으로 들어가요.
   - 새 모둠에는 **바로 전 모둠 친구가 최대 2명까지만** 함께 들어가요(3명 이상 다시 모이지 않아요).
4. 수업이 끝나면 [수업 끝내기] → [결과 엑셀(CSV)]로 학생별 기록을 내려받아요.

### 자동 배정이 기다리는 경우
- 4명 모둠이 혼자 먼저 끝나면, 4명끼리는 규칙을 지킬 수 없어서 **다른 모둠이 끝날 때까지** 대기실에서 기다려요. (기다리는 동안 대기실에서 카드 공부를 할 수 있어요.) 그래서 게임 시간은 5~7분을 추천해요.
- 반 전체가 5명 이하처럼 섞을 친구가 아예 없을 때만, 같은 친구들과 다시 만나요.

## 2. 게임 규칙

1. 같은 카드 4장을 모으면 책 1권. 책을 가장 많이 만든 사람이 1등!
2. 내 차례: **친구**를 누르고, 요청할 **내 카드**를 골라 **요청하기**를 눌러요.
3. 보기 3개 중 **알맞은 영어 문장**을 골라 큰 소리로 물어봐요.
   - 문장을 틀리면 친구에게 받을 수 없어요 → 연못에서 1장 가져가고 차례 끝.
4. 친구가 그 카드를 가지고 있으면 → 친구는 알맞은 대답을 골라요 → 카드를 모두 받고 **한 번 더!**
5. 없으면 → **Go fish!** 연못에서 1장. 원하던 카드를 낚으면 한 번 더!
6. 모든 책이 완성되거나 게임 시간이 끝나면 게임 끝.

| 단원 | 물어보는 문장 | 대답 (있을 때 / 없을 때) |
|---|---|---|
| 11단원 | Do you know about hanbok? | Yes, I do. Here you are. / No, I don't. Go fish! |
| 12단원 | Don't forget to recycle. / We should save water. | Sure! Here you are. / Sorry. Go fish! |

- 오답 보기는 지도서 유의점(should 뒤 동사원형, forget 뒤 to+동사원형, Do you know about ~?)에 맞춰 만들어요. 예: `We should to save water.`, `Don't forget recycle.`, `Do you know hanbok about?`
- 대답을 틀리게 고르면 게임이 바른 대답으로 고쳐 주고, 기록에는 오답으로 남아요.

### 카드 (23종)
- **11단원(12)**: hanbok 한복, gat 갓, kimchi 김치, tteokbokki 떡볶이, songpyeon 송편, gongginori 공기놀이, tuho 투호, hanji 한지, fan 부채, mask 탈, yutnori 윷놀이, norigae 노리개
  - 문장: Do you know about hanbok? (부채·탈은 Do you know about the Korean fan / mask?)
- **12단원(11)**
  - We should ~.: save the Earth, save energy, save water, plant trees, protect animals, clean the oceans
  - Don't forget to ~.: recycle, reuse, use a bike, use public transportation, reduce trash
- 교사 화면에서 **11단원** 또는 **12단원**을 고르면 그 단원 카드만 나와요(섞지 않아요). 처음 설정은 11단원이에요.
- 한 게임에 3명은 9종, 4명은 10종, 5명은 11종이 나와요.
- 카드 낱말과 문장은 `cards.js`, 카드 그림은 `public/assets/v10/cards/`에서 바꿀 수 있어요.

## 반 전체 랭킹
- 점수: 책 1권 **+10** · 바른 문장으로 물어보기 **+2** · 바른 대답 **+1** · 모둠 1등 **+5** · 한 판 참여 **+1**
- 같은 점수면 모은 책 수 → 1등 횟수 순서로 등수를 정해요. (연습봇은 랭킹에서 빠져요)
- 점수는 `server.js` 맨 위 `SCORE` 한 줄에서 바꿀 수 있어요.
- 교사 화면: '반 전체 랭킹'(시상대 + 전체 순위), **📺 크게 보기**(TV·전자칠판용 전체 화면), **초기화**(다른 반 수업 전에), 엑셀에 반 등수·점수 포함
- 학생 화면: 대기실에 '우리 반 랭킹 TOP 5'와 내 점수·내 등수, 게임 중 '내 책' 칸에 내 점수, 결과 화면에 이번 판 점수(+N점)와 반 등수

## 3. 교사 화면 기능
- **게임 설정**: 카드 단원(11단원 / 12단원), 게임 시간(3·5·7·10·15분), 자동 모둠 배정 켜기·끄기 — 다음 모둠부터 적용
- **대기실**: 기다리는 학생과 바로 전 모둠 번호, 기다린 시간
- **모둠 현황**: 모둠별 차례, 카드 수, 모은 책, 남은 시간, (전 ○번) 표시, 모둠 끝내기
- **학생별 기록**: 게임 수, 1등, 모은 책, 문장 정답률, 대답 정답률 / 내보내기
- **🤖 연습봇 넣기**: 혼자 미리 해 볼 때 컴퓨터 학생을 넣어요. 수업 전에 [봇 모두 빼기]를 눌러 주세요.

## 5. 인터넷에 올리기 (Render 무료)
여러 학생이 동시에 접속하는 게임이라 GitHub Pages가 아니라 **서버**가 필요해요.

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올려요(`node_modules` 폴더는 빼고).
2. [render.com](https://render.com) → New → **Web Service** → 방금 만든 저장소 선택
3. 설정
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
4. 몇 분 뒤 나오는 주소(`https://○○○.onrender.com`)가 학생 주소, 뒤에 `/teacher`를 붙이면 교사 주소예요.

⚠️ 무료 서버는 15분 동안 아무도 안 쓰면 잠들어요. **수업 시작 2~3분 전에 교사 화면을 먼저 열어** 서버를 깨워 두세요. 서버가 다시 시작되면 기록이 지워지니, 수업이 끝나면 결과 CSV를 받아 두세요.
