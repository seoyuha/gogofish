GO GO FISH 8차: v7 디자인 전면 적용 + 실제 화면 점검 후 수정

v7 패키지의 그래픽·CSS(modern-v2~v7, teacher-v2~v7)를 그대로 쓰고,
실제 서버를 돌려 학생 4명+연습봇으로 게임을 끝까지 진행하며 화면을 캡처해 고쳤습니다.

새로 쓴 그래픽
- assets/card-fronts 23종(UNIT 11 분홍 / UNIT 12 파랑 완성 카드)을 실제 카드로 사용
  (손패, 대기실 카드 공부, 문장 고르기·대답 창, 책 완성 화면)
- 말(폰) 5색: 모둠 자리 순서대로 빨강·파랑·노랑·초록·보라
  → 한 학생은 테이블·소개·결과·교사 화면에서 늘 같은 색
  (v7에서는 화면 위치에 따라 색이 정해져서 같은 학생이 화면마다 다른 색이었음)

고친 점
- 소개 화면 말이 흐린 흰색으로 보이던 문제
- 대기실 말 위에 분홍 동그라미가 겹치던 문제
- songpyeon, Ganggangsullae 같은 긴 낱말이 중간에서 끊기던 문제
- 휴대폰에서 위쪽 줄(?) 버튼이 다음 줄로 넘어가던 문제
- 휴대폰에서 빈 대화창이 회색 띠로 남던 문제
- 고른 카드가 위로 올라올 때 윗부분이 잘리던 문제
- 대화창 맨 위 줄이 반쯤 잘려 보이던 문제 → 최근 2줄만 또렷하게
- 책 완성 효과: 'BOOK!'과 'BOOK COMPLETE' 제목이 겹치던 것을 시안의 '책 완성!' 팝업 모양으로

추가 파일: assets/modern-v8.css, assets/teacher-v8.css
바뀐 파일: public/index.html, public/teacher.html (말·카드 그리는 부분만)
그대로인 것: server.js, cards.js, 게임 규칙, 자동 모둠 배정
