GO GO FISH 현대적 보드게임 디자인 2차 적용 패키지

1. 기존 게임 규칙, server.js, cards.js, JavaScript 및 소켓 이벤트는 변경하지 않았습니다.
2. public/assets 폴더에 다음 파일이 추가되었습니다.
  - modern-v2.css / teacher-v2.css : 학생·교사 화면 스타일
  - pawn-*.svg : 플레이어 색상 토큰 5종
  - card-back.svg : GO GO FISH 카드 뒷면
  - button-*-normal/pressed/disabled.svg : 버튼 상태 12종 (투명 여백 SVG)
3. 실제 실행 화면은 참고 시안 이미지와 정확히 동일하지 않습니다. CSS로 구현 가능한 범위의 디자인 개선본입니다.
4. 원래 게임에서 플레이어의 동물 이모지가 내부 데이터로 남아 있지만, 로비/교사화면/게임 플레이어 초상은 색상 토큰 그래픽으로 덮었습니다. 채팅 안내 텍스트의 일부 이모지는 잔존할 수 있습니다.
5. 버튼 SVG는 추후 원하는 요소에 연결하거나 디자인 소스로 사용할 수 있습니다. 현재 버튼 화면은 CSS로 스타일링했습니다.
6. 로컬 실행: npm install 후 npm start (서버 안내 주소로 접속). 서버 실행 환경 테스트는 완료하지 못했습니다.
7. 완성된 이미지 목업은 검증된 실제 앱 화면 캡처가 아니라 디자인 시안입니다.
