GO GO FISH 10차: 확정 광택형 UI 시안 그대로 전면 교체 (GO_GO_FISH.zip 기준)

화면을 새로 만들었어요 (시안 9장 기준)
- 시작 화면: 입체 로고 · "함께 배우고, 함께 완성하는 영어 카드 게임" · 노란 '게임 시작하기' · 게임 방법 · 설정(소리 켜기/끄기)
- 대기실: '← 나가기' · '게임 대기실' 입체 제목 · 반 코드와 인원 · 말 카드(Player N, 이름, 준비완료) · 파란 큰 알림 버튼
- 새 모둠: 입체 제목 · '○번 모둠 · 11+12' · 말 카드 · 카운트다운 원 · 규칙 3줄(책·말풍선·트로피 아이콘)
- 게임: 위쪽 정보 줄(모둠·남은 시간·연못 카드·완성된 책) · 파란 소리/도움말 버튼 · 원목 테이블
        플레이어 칸(말 + 이름 + 남은 카드 칸 + 장수), 차례인 친구는 노란 테두리·왕관·'차례' 표시
        가운데 카드 더미 + 지금 오가는 카드 · '최근 대화' 줄 · '내 카드(N장)' · '내 책(완성한 세트)'
- 카드 요청 창(새로 생김): 친구를 누르면 'OO에게 카드를 요청하세요!' → 전체/11단원/12단원 → 요청하기
- 문장 고르기 창: 파란 제목 띠 · Unit 표시 · 동그라미 보기(고르면 노랗게) · 시계 타이머 · 다시 고르기
- 대답 창 · 게임 방법 · 설정 창도 같은 모양
- 책 완성: 파란 '책 완성!' 배지 · 햇살 · 색종이 · 카드 4장 부채꼴 · 초록 '좋아요!'
- 결과: 트로피 리본 · '게임 종료!' · 1등 왕관과 순위 번호 · 책 아이콘 'N권' · '다시 하기'(새 모둠) · '처음으로'
- 교사 관리: 시안처럼 로고·교사 관리·연습봇·엑셀·수업 끝내기 / 접속 코드(복사·QR·링크 복사) / 수업 설정
            / 현황 4칸 / 대기실 말 카드 / 게임 중인 모둠(남은 카드·완성한 책 막대) / 학생별 접속 현황 / 완료된 게임 기록

그림 (public/assets/v10/)
- 확정 UI 시트에서 오려 낸 것: 로고, 말 5색, 왕관, 카드 뒷면·카드 더미, 작은 아이콘(사람·시계·카드·책·말풍선·트로피), 동그란 버튼 아이콘(홈·소리·도움말·뒤로·닫기·새로고침·책·톱니)
- 버튼은 시안의 광택 알약 모양을 CSS로 그대로 그렸어요(글자를 바꿔도 깨지지 않게)
- 11단원 카드 12종: 보내 주신 실사진 카드 사용
  · 11장에 있던 흰 줄(투명하게 뚫린 자국)을 지우고, 카드 틀을 다시 그려 12장 모두 같은 모양으로 맞춤
- 12단원 카드 11종: 보내 주신 카드의 한글이 □□□로 깨져 있어서, 11단원 카드와 같은 틀로 새로 만듦
  · Don't forget to ~ 카드는 초록 틀, We should ~ 카드는 파란 틀, 그림은 같은 모양의 Noto 이모지(고해상도)
- 글꼴: Pretendard · Jua · Fredoka를 게임 안에 넣음(학교망에서 구글 글꼴이 막혀도 그대로 보임)
- QR 코드도 게임 안에서 만듦(외부 사이트 필요 없음)

서버: 게임 기록에 말 색과 게임 시간만 더함(교사 '완료된 게임 기록' 표용). 규칙·자동 모둠 배정은 그대로.
이전 디자인 파일(v2~v9)은 design-history/ 폴더로 옮겼어요(게임에서는 쓰지 않음).
