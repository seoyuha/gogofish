GO GO FISH 3차 그래픽 개선 패키지

기준: 2차 디자인 적용판
변경 항목
- 11단원 12종 + 12단원 11종 = 총 23종의 개별 카드 그림 SVG(public/cards)
- 전체 카드 앞면 시안 23종 SVG(public/assets/card-fronts)
- 카드 뒷면 새 SVG(public/assets/card-back-v3.svg)
- 학생 게임 화면 모던 원목 테이블, 카드 기본/선택/교환 강조, 책 완성 및 모달 효과를 CSS로 개선
- 태블릿에서 동작하도록 CSS 효과만 사용, 감소된 모션 설정 대응
- 기존 서버, 카드 텍스트, 로직 및 교사용 기능 수정 없음

주의
- 카드는 SVG의 시스템 이모지 글리프 기반이므로 기기/브라우저에 따라 그림 모양이 달라질 수 있습니다.
- 카드 앞면 시안 SVG는 별도 그래픽 자산이며 실제 화면에서는 /cards/ 의 그림만 사용합니다.
- 애니메이션은 기존 상태 변경 시 작동하는 CSS 개선으로 카드 교환 전용 새 통신 이벤트를 추가하지 않았습니다.
- 실행 전 npm install 후 npm start; 학생 http://localhost:3000/ 교사 http://localhost:3000/teacher (서버 포트는 설정에 따라 다름).
